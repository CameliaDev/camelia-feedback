# camelia-feedback

Public feedback inbox for the [Camelia](https://github.com/CameliaDev/Camelia-Agent) desktop agent.

Camelia's in-app feedback flow can point here so bug reports, feature ideas, and session notes land in one place without cluttering the main agent repo.

## How to send feedback

1. **GitHub Issues (preferred)** — open an issue in this repo: describe what you expected, what happened, OS, and Camelia build if known.
2. **Pull requests** — small doc or template fixes welcome.
3. **Inbox file** — drop a short markdown note under `feedback/` (one file per report) if you prefer a file-based trail; keep secrets out of git.

Related product: [Camelia-Agent](https://github.com/CameliaDev/Camelia-Agent).
